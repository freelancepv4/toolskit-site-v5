Diese Erklärung beschreibt, was mit Ihren Dateien, Ihren Eingaben und Ihren Daten geschieht, wenn Sie ToolsKit nutzen. Stand: {{updated}}.

Zusammenfassung

  • Die ToolsKit-Tools laufen in Ihrem Browser. Dateien, die Sie hinzufügen, und Texte, die Sie eintippen, werden auf Ihrem Gerät verarbeitet und nicht zu ToolsKit hochgeladen.
  • ToolsKit setzt keine Cookies, zeigt keine Werbung und nutzt derzeit keine Analyse.
  • Ihr Browser speichert eine kurze Liste zuletzt geöffneter Tool-Namen, Ihre Sprachauswahl (falls Sie eine treffen) und einen Lebenslauf-Entwurf, wenn Sie „Entwurf speichern“ wählen. All das bleibt auf Ihrem Gerät.
  • Der Hosting-Anbieter der Website verarbeitet übliche Anfrage-Protokolle, wie jeder Webhoster.
  • Wenn Sie uns eine E-Mail schreiben, erhalten wir Ihre E-Mail-Adresse und Ihre Nachricht.

Ihre Dateien und Eingaben

Die PDF-, Bild-, QR-Code-, Umrechner-, Rechner-, Lebenslauf- und Social-Media-Tools arbeiten mit JavaScript im Tab Ihres Browsers. Die Dateien, die Sie auswählen, werden von Ihrem Browser gelesen, und die Ergebnisse entstehen auf Ihrem Gerät; der Download wird von Ihrem Browser erzeugt. Kein ToolsKit-Code sendet Ihre Dateien oder die Texte, die Sie eintippen, an ToolsKit oder an andere. ToolsKit kann sie daher weder einsehen noch aufbewahren oder wiederherstellen.

Weil die Verarbeitung auf Ihrem Gerät stattfindet, hängt die Leistung vom Speicher Ihres Geräts ab, und ein Tool kann bei sehr großen Dateien scheitern. Nach dem Schließen oder Neuladen der Seite wird nichts gespeichert, mit Ausnahme der im nächsten Abschnitt genannten Einträge.

Was Ihr Browser speichert

  • Zuletzt verwendete Tools – die Namen (IDs) von bis zu sechs Tools, die Sie geöffnet haben, im lokalen Speicher Ihres Browsers, damit die Seite „Alle Tools“ sie auflisten kann. Sie können die Liste auf der Seite Alle Tools oder durch Löschen der Website-Daten Ihres Browsers leeren.
  • Sprachauswahl – wenn Sie in der Sprachliste eine Sprache wählen, wird deren Kürzel (zum Beispiel „de“) im lokalen Speicher Ihres Browsers abgelegt, damit die Startseite diese Sprache beim nächsten Mal zuerst auflisten kann. Es wird nie zur Weiterleitung verwendet und nirgendwohin gesendet.
  • Lebenslauf-Entwurf – nur, wenn Sie im Lebenslauf-Builder „Entwurf speichern“ wählen. Er bleibt im lokalen Speicher Ihres Browsers, bis Sie „Entwurf löschen“ wählen oder die Website-Daten löschen. Löschen Sie ihn auf einem gemeinsam genutzten Computer, bevor Sie gehen.

Der eigene Code von ToolsKit setzt keine Cookies.

Analyse und Werbung

ToolsKit nutzt derzeit weder Analyse noch Werbung und lädt keine Tracking-Skripte. Der Code der Website enthält eine optionale, einwilligungsbasierte Messfunktion, die ausgeschaltet ist. Sollten Analyse oder Werbung jemals aktiviert werden, wird zuerst diese Erklärung aktualisiert, es wird eine Einwilligung eingeholt, soweit das Gesetz dies verlangt, und Dateiinhalte, eingegebene Texte und Suchtexte werden nicht erfasst.

Server-Protokolle

Wenn Ihr Browser eine Seite anfordert, erhält der Hosting-Anbieter technische Informationen wie Ihre IP-Adresse, die angeforderte Seite, die Uhrzeit sowie Browser- und Gerätetyp. Hosting-Anbieter nutzen diese Angaben üblicherweise, um die Website auszuliefern, sie zu schützen und Probleme zu untersuchen, und bewahren sie nach ihren eigenen Richtlinien für einen begrenzten Zeitraum auf. Dies sind ausschließlich Anfrageinformationen: Die ToolsKit-Tools senden Ihre Dateien oder Eingaben nicht in diesen Anfragen mit. Der Hosting-Anbieter kann diese Daten in verschiedenen Ländern verarbeiten.

Wenn Sie uns kontaktieren

Wenn Sie eine E-Mail senden, erhalten wir Ihre E-Mail-Adresse und das, was Sie schreiben. Wir verwenden sie nur, um zu antworten, ein gemeldetes Problem zu untersuchen und den Austausch in angemessenem Umfang zu dokumentieren. Wir löschen sie, wenn sie nicht mehr benötigt wird, und früher, wenn Sie darum bitten. Bitte senden Sie keine privaten Dateien, Passwörter oder Finanzdaten.

Aufbewahrung

ToolsKit speichert keine Kopien Ihrer Dateien oder Eingaben. Einträge im lokalen Speicher Ihres Browsers bleiben, bis Sie sie löschen. E-Mails werden wie oben beschrieben aufbewahrt. Server-Protokolle bewahrt der Hosting-Anbieter für seine eigene Aufbewahrungsfrist auf.

Sicherheit

Dass die Verarbeitung in Ihrem Browser stattfindet, bedeutet, dass Ihre Dateien nicht zu einem ToolsKit-Server übertragen werden. ToolsKit soll über HTTPS ausgeliefert werden und sendet Sicherheits-Header, die die Seite darauf beschränken, nur Code von der eigenen Website zu laden. Kein System ist vollkommen sicher: Halten Sie Ihren Browser aktuell und seien Sie auf gemeinsam genutzten Computern vorsichtig. Beachten Sie, dass ein WLAN-QR-Code das Netzwerkpasswort in lesbarer Form enthält.
